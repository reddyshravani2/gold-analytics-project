# Gold Analytics Project

A data analytics project focused on gold pricing trends, digital gold, market reliability, and global investment analysis using SQL, Snowflake, Power BI, and Git.

## 🟡 Project Scope
This project will cover:
- Historical gold prices
- Digital gold platforms and usage
- Country-wise gold reserves and trade
- Market trends and volatility
- SQL data modeling and querying
- Power BI analytics and dashboards
- Snowflake integration
- Git repository for version control

## 🛠️ Tech Stack
- SQL (MySQL/PostgreSQL)
- Snowflake
- Power BI
- Git & GitHub
- Excel / CSV sample data
